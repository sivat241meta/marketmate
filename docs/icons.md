# Icons (Task 79)

Navigation, action, stat and empty-state icons are Microsoft's Fluent Emoji,
Flat style (MIT licence), downloaded from the official repository
https://github.com/microsoft/fluentui-emoji (main branch) as small SVGs.
Each file below keeps its upstream bytes; the licence is saved as
`app/web/static/icons/fluent/LICENSE`.
Line icons (`ui.icon()`) stay for small controls: chevrons, close, edit,
play, + / -, search glyphs and arrows. The WhatsApp logo is never used;
WhatsApp buttons use the speech balloon (`chat.svg`).
